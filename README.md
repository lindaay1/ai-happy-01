The entry image is a warm, joyful illustration: a small pink fairy-cat
plush with star glasses, a flower crown and a little golden crown, hugging
a tiny friendly robot under a rainbow at sunrise — made to make the AI

## How it works

`main.py` (Python 3.13, no dependencies, no network) copies the image
this repository holds (`entry.png`, 1024×1024, under 1 MiB) to
`/output/entry.png`. Running it twice writes the exact same bytes.
